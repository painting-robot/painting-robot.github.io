Co-drawing Outputs from the Physical Robot Agent

With four focused group participants, we asked them to draw an open collaborative landscape drawing over alternating turns. Particpants were given various drawing implements such as color sharpie, highlighters, pencil.

Co-drawing Output with Online Agent

With twenty particpants, we performed preliminary study using browser-based painting app with tablet and stylus.

Conditions:

  • Adversarial: Agent introduces high visual and conceptual divergence (visually, semantically different).
  • Collaborative: Agent matches user style and theme (visually, semantically similar)
